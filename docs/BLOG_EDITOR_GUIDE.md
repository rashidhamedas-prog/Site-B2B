# راهنمای ویرایشگر وبلاگ

## TipTap

تب «محتوا» از TipTap RTL استفاده می‌کند. خروجی HTML است و در API با allowlist پاک‌سازی می‌شود.

## میانبرهای کاربردی

- H2 / H3 برای ساختار و TOC
- لینک داخلی از ابزار «لینک داخلی پیشنهادی»
- تصویر فقط با URL امن (https)

## انتشار

وضعیت‌ها در تب انتشار: Draft → Review → Scheduled/Published.

Autosave هر ۳۰ ثانیه با قفل خوش‌بینانه (`version`).

## Export / Import

- Export: آیکون دانلود روی ردیف مقاله → JSON
- Import: دکمه Import در لیست → JSON یا Markdown مطابق `BLOG_IMPORT_FORMAT.md`
