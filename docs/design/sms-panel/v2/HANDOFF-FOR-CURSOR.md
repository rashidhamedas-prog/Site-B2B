# HANDOFF-FOR-CURSOR — پنل پیامک v2
مرجع طراحی: `UI-SPEC.md` (همین پوشه) + `../ui/UI-SPEC.md` (v1) + `../spec.md`. ماکاپ‌ها: `screens/*.html`. **هیچ merge یا تغییر زنده‌ای بدون GO کتبی خود حامد رشید.**

## ۱. هدف
بازطراحی `/admin/sms` با انتخاب مخاطب از ۳ منبع، سگمنت‌ساز، پیش‌نمایش تعداد/اعتبار، قالب با متغیر، زمان‌بندی با ساعات مجاز و مرحله تأیید؛ RTL، واکنش‌گرا ۳۶۰–۱۴۴۰، WCAG 2.2 AA.

## ۲. معیار پذیرش هر تب
- **داشبورد**: KPIهای v1 + تفکیک منبع؛ skeleton/خالی/خطا.
- **ارسال تکی**: جستجو در ۳ منبع؛ کارت مخاطب با منابع/رضایت/لغو؛ PartCounter زنده؛ PROMO برای لغوکرده/بدون رضایت غیرفعال با دلیل؛ خطاهای 403/422/429 فارسی.
- **ارسال انبوه**: [ ] حداقل یک منبع الزامی [ ] dedupe بر شماره نرمال‌شده [ ] حذف لغو/سیاه غیرقابل‌خاموش [ ] شرط‌های AND با ۸ فیلد UI-SPEC §۱ [ ] ذخیره/بارگذاری سگمنت [ ] پنل پیش‌نمایش با ۵ ردیف حذف + گیرنده نهایی + پارت + مصرف پیامک + هزینه «برآورد» [ ] پارت: ≤۷۰→۱، بیشتر ⌈n/۶۷⌉، با «لغو11» و بیشترین طول پس از جایگذاری [ ] زمان خارج ۰۸–۲۱ تهران رد + پیشنهاد اولین زمان مجاز [ ] مودال تأیید با تایپ تعداد، فوکوس روی «انصراف» [ ] اعتبار ناکافی = غیرفعال [ ] شمارش در لحظه ارسال دوباره محاسبه.
- **قالب‌ها**: CRUD، chips متغیر، متغیر ناشناخته = خطا، پارت تخمینی.
- **مخاطبان**: یک ردیف/شماره، badge چند منبع، زیرتب سگمنت‌ها، موبایل ماسک برای نقش غیرمدیر.
- **گزارش‌ها / لغو و سیاه / فعالیت‌ها**: رفتار v1 + فیلتر منبع؛ لاگ ساخت/ویرایش سگمنت.
- **تنظیمات**: v1 + قیمت واحد اختیاری + آستانه تأیید مدیر.
- **سراسری**: بدون اسکرول افقی در ۳۶۰px؛ لمس ≥44px؛ input 16px؛ فقط CSS منطقی؛ Vazirmatn؛ کنتراست ≥4.5:1؛ فوکوس مرئی و پوشیده‌نشده.

## ۳. داده لازم از backend (پیشنهادی)
- `GET /admin/sms/audience/sources` → شمارش هر منبع + وضعیت دسترس‌پذیری.
- `POST /admin/sms/audience/preview {sources[], rules[], templateId|text, class}` → `{total, duplicates, optedOut, noConsent, invalid, final, partsPerMsg, totalParts, unitPrice|null, sample[20], partialSources[]}`.
- `GET/POST/PUT/DELETE /admin/sms/segments`؛ لیست فیلدها و عملگرها (`/audience/fields`) و مقادیر شهر/برچسب.
- متغیرهای مجاز هر منبع؛ ساعات مجاز و قیمت واحد از تنظیمات؛ اعتبار فعلی؛ آستانه تأیید.
- خطاها با `code` ماشینی + پیام فارسی (400/402/403/409/422/429).

## ۴. چیزهایی که نباید تغییر کنند
مسیر `/admin/sms` و نام ۹ تب؛ منطق ارسال/provider (sms.ir)، صف، retry، poller و جداول موجود (`MarketingSuppressionEntity` منبع حقیقت لغو)؛ قفل «لغو11»؛ RBAC چهار نقش v1؛ عدم نمایش کلیدها؛ OTP/خدماتی خارج از این ویزارد. بدون migration مخرب و بدون deploy/merge بدون GO کتبی حامد.
