**به‌روزرسانی ۲۰۲۶-۱۰-۲۷ (۱۶:۳۰ تهران):** تصمیم‌های حامد اعمال شد (بخش ۴). **وضعیت:** فقط سند. هیچ تغییری در کد، env، DB، سرور یا کانال‌ها داده نشده است. اجرای هر بند فقط با GO نوشتاری حامد.

**منابع ادغام:** `prompt-redesign-v1.md` (Brief)، `req-telegram.md` (TG)، `req-rubika-bale.md` (RB)، `req-technical.md` (TECH)، `req-strategy.md` (STR).
**مسیر پنل (تأییدشده با بازبینی فقط‌خواندنی ریپو، commit `3a5a2155`):** `apps/web/src/components/admin/AdminOmnichannel.tsx` وجود دارد. سند TECH فایل‌های `apps/web/src/app/admin/omnichannel/page.tsx`، `admin-omnichannel-ui.tsx` و `admin-omnichannel-outbox.ts` را هم نام می‌برد؛ ارجاع STR به «حدود خط ۲۰۲۲» (رنگ قرمز هشدار) باید در PR مربوط دوباره با شماره خط دقیق تأیید شود.
