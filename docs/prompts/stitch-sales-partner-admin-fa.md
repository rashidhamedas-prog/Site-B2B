# پرامپت Stitch — داشبورد همکار بازاریاب ترنم (ادمین + پنل)

طراحی Web (نه App)، فارسی RTL، برند پوشاک ترنم.

## هویت بصری

- پالت: سبز `#1B5C4A`، سبز تیره `#0F2F28`، طلا `#C9A84C`، کرم `#F6F1E8`، متن `#1A1A1A`، بوردر ملایم سنگ.
- سبک: لوکس مینیمال fashion ops — نه dark OLED، نه purple gradient، نه glass سنگین.
- اعداد tabular؛ badge وضعیت رنگی ملایم؛ کارت بدون سایه ضخیم؛ گوشه ~16–20px.
- الگو از داشبوردهای KPI مدرن (کارت متریک + جدول فیلتردار + تایم‌لاین سوابق) با شخصی‌سازی برند ترنم.

## صفحه ۱ — ادمین: داشبورد گزارش‌دهی

عرض دسکتاپ ۱۲۰۰px. بخش‌ها:

1. هدر: عنوان «همکار بازاریاب» + وضعیت برنامه (خاموش/پیش‌نمایش/آزمایشی/زنده) + دکمه تازه‌سازی.
2. ردیف ۴ KPI: درخواست‌های در انتظار، همکاران فعال، نرخ تأیید مشتری، پورسانت قابل‌برداشت برنامه (با برچسب تومان و توضیح کوتاه که تخمین نیست).
3. دو ستون: قیف وضعیت پیش‌سفارش‌ها (نوار افقی) | توزیع وضعیت همکاران.
4. جدول فشرده «نیاز به اقدام»: درخواست PENDING + سفارش منتظر تأیید.
5. فید سوابق اخیر (timeline) با action خوانا به فارسی.

## صفحه ۲ — ادمین: درخواست‌ها

جستجو + فیلتر وضعیت. کارت/ردیف هر درخواست: نام، تلفن ماسک، تاریخ، badge وضعیت، اکشن‌های تأیید / تکمیل اطلاعات / رد با دلیل. Empty state حرفه‌ای.

## صفحه ۳ — ادمین: گزارش و سوابق

تب‌های داخلی: خلاصه برنامه | سوابق تصمیم (فیلتر نوع هدف) | پیوند سریع به تسویه و قوانین. بدون اختراع عدد هدف فروش.

## صفحه ۴ — پنل بازاریاب (موبایل ۳۹۰px)

خانه: کارت هویت + ۳ متریک پورسانت (نگهداری / قابل‌برداشت / پرداخت‌شده) + نوار پیشرفت ساده + CTA محصولات و سفارش جدید + هشدار stale. ناوبری پایین ۴تایی. همان پالت؛ موبایل‌اول.

## ممنوع

ایموجی به‌جای آیکون، شلوغی hero، کارت‌های زیاد تزئینی، اختراع درآمد تضمینی.
