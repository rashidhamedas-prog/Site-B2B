# Stitch prompt — منوی retail + جای کپی هیرو (پوشاک ترنم)

برای [Stitch](https://stitch.withgoogle.com/) — RTL فارسی. خروجی فقط مرجع بصری است؛ پیاده‌سازی با کامپوننت‌های پروژه.

## برند

- Primary green `#1B5C4A`
- Gold `#C9A84C`
- Surface cream `#F6F1E8`
- Ink `#1a1a1a`
- فونت: فارسی مدرن (بدون Inter/Roboto)

## صفحه ۱ — هدر دسکتاپ

افقی RTL: لوگو راست، لینک‌های منو وسط-راست، آیکون جستجو/حساب/سبد چپ.

لینک‌ها: صفحه اصلی، جدیدترین‌ها، دسته‌بندی▾، کلکسیون، وبلاگ، همکار بازاریاب، درباره ما، تماس با ما.

**حالت‌ها (یک نوار نشان بده):**

1. Default — خاکستری مرکب
2. Hover — مرکب کامل + خط طلایی نازک که از inline-start رشد می‌کند (`scaleX`)
3. Active/current — خط طلایی ثابت + وزن کمی بیشتر
4. Focus-visible — حلقه طلایی ۲px
5. دسته‌بندی باز — شورون چرخیده + همان خط طلایی

بدون کارت، بدون pill، بدون glow بنفش. motion سبک و لوکس مد.

## صفحه ۲ — هیرو محصول روی پلیت سبز/آبی

بنر full-bleed: محصول (مانتو) سمت **چپ** تصویر؛ فضای خالی رنگی سمت **راست**.

بلوک عنوان + توضیح + CTA طلایی فقط روی فضای خالی **راست** (inline-start در RTL). هرگز روی تنه محصول ننشیند.

اسکریم نرم از راست؛ بدون پنل باکس‌شده روی عکس.
