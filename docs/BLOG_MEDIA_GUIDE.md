# راهنمای رسانه وبلاگ

## آپلود

از پنل `/admin/blog` → ابزار «کتابخانه رسانه»:

1. alt را قبل از آپلود وارد کنید
2. فایل را آپلود کنید (MinIO)
3. متادیتا با `POST /v1/blog/admin/media/register` ثبت می‌شود
4. با کلیک روی تصویر، URL کپی می‌شود

## فیلدهای مهم

- `altText` (الزامی برای سئو)
- `contentHash` برای تشخیص تکراری
- `focalPointX/Y` اختیاری
- حذف رسانه، فایل را از MinIO هم پاک می‌کند

## در ویرایشگر TipTap

از دکمه تصویر می‌توانید URL ثبت‌شده را درج کنید. همیشه `alt` بگذارید.
