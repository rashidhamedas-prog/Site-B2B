# 2026-10-02 — ریشه قطعی ایران + سخت‌سازی origin

تسک: `TASK-20261002-001`  
عمق: skill-top full

## حکم

اپ و فایروال فروشگاه ایران را بلاک نمی‌کنند. قطعی «بدون فیلترشکن باز نمی‌شود» از **لبه** است:

1. هر دو زون دوباره **ابر نارنجی Cloudflare** بودند (AAAA + HTTP/3 + anycast). این همان رگرسیون بعد از فیکس ۱۴ سپتامبر است.
2. روی TLS ویترین تکی (`www.poshaktaranom.ir`) مسیر پروکسی تونل (`/connect/…`) اینکلود شده بود. DPI ایران SNI فروشگاه را با ترافیک تونل یکی می‌گیرد و دامنه/IP را لیست می‌کند.
3. همان IP عمومی (`5.75.200.102`) پورت‌های تونل جدا هم گوش می‌دهد. بعد از خاکستری‌شدن DNS، اگر IP لیست شود سایت دوباره می‌میرد.

«کلودفلر حرفه‌ای» برای این پروژه یعنی **DNS + گواهی/کش اختیاری برای رکوردهای غیر ویترین**، نه ابر نارنجی روی هوم ایران. پلن رایگان IPv6 را وقتی پروکسی روشن است خاموش نمی‌کند.

## پنج زاویهٔ بررسی (دفاعی، بدون اکسپلویت)

| نقش | یافته | اقدام |
| --- | --- | --- |
| لبه DNS | A/AAAA کلادفلر روی `.ir` / `.com` / `api` | gray-cloud + حذف AAAA فروشگاه |
| مرورگر ایران | Happy Eyeballs روی IPv6 خراب + QUIC | HTTP/3 و IPv6 سازگاری خاموش |
| SNI فروشگاه | اینکلود تونل روی ویترین تکی | حذف اینکلود؛ فقط فروشگاه روی این هاست |
| origin abuse | `/api/` بدون `limit_req`؛ Swagger 200 در prod | rate-limit + مخفی کردن docs |
| سطح میزبان | UFW برای ۳۰۰۰/۸۰۰۰ باز؛ fail2ban فقط sshd | بستن ruleهای بلااستفاده؛ jail nginx بعد از لیمیت |

عمداً JWT HttpOnly و قفل هاست ادمین در این تسک لمس نشد (ریسک نشست / رگرسیون پنل).

## تأیید بعد از اعمال

- `nslookup` فروشگاه → فقط `5.75.200.102`، بدون AAAA
- `curl -sI` → `Server: nginx`، بدون `alt-svc: h3`
- `/api/docs` روی origin → غیر ۲۰۰ در production
- گوشی ایران، VPN خاموش: هر دو هوم HTML
