## نتیجه

گلوگاه رشد ایندکس نیست. تکی و عمده هنوز روی برند دیده می‌شوند. مشکل اصلی سرعت موبایل عمده است (در کنسول تا ۳۰ مرداد: ۱۱ URL با LCP بالای ۴ ثانیه). تکی هنوز دادهٔ CrUX ندارد.

امروز روی سرور این‌ها قطعی بود:

- تصویر هیرو/فونت/لوگو با `Cache-Control: max-age=0` سرو می‌شد؛ مرورگر هر بار دوباره دانلود می‌کرد.
- در هوم عمده، لوگو قبل از هیرو preload می‌شد.
- هیرو موبایل عمده ۸۶ کیلوبایت بود (تکی ۴۲).
- در JSON-LD تکی، آدرس تصویر محصول روی دامنهٔ `.com` بود.

روی خود کنسول امروز کلیک انجام نشد؛ ابزار مرورگر Cursor به نشست لاگین وصل نشد. تنظیمات درست قبلی (مالکیت دامنه، GA4، سایت‌مپ apex، Include برای AI) را دست نزنید. Validate Fix روی ریدایرکت / noindex / ۴۰۴ نزنید.

## تغییر کد این تسک

کش ۳۰روزه برای بنر و لوگو (بدون `max-age=0`)، `fetchPriority=low` روی لوگوی هدر عمده، تصویر JSON-LD روی همان هاست صفحه، فشرده‌سازی اسلاید اول عمده (موبایل ۳۸ کیلوبایت).

بعد از دیپلوی: یک‌بار ایندکس هوم تکی و عمده اگر ۲۰۰ و خود-کانونیکال باشند. Validate Fix تصویر Merchant فقط بعد از خزش مجدد. CWV را تا ۲۸ روز Validate Fix نکنید.
