# کاتالوگ همکار، سفارش جدید، معرفی پیامک

تاریخ: 2026-10-18

## شواهد

`GET /v1/products?channel=RETAIL` روی API زنده: کل منتشرشده ۷۹، موجود (`inStock=1`) ۵۸. عدد دورِ «همه» در پنل همان فیلتر `retailStock > 0` بود، نه سقف صفحه.

## رفتار جدید

- کاتالوگ همکار پروجکشن کالاهای منتشرشدهٔ تکی است. پیش‌فرض «همه». فیلتر «قابل سفارش» و «ناموجود» جداست. سفارش مشتری برای ناموجود بسته است.
- سفارش جدید با جستجوی همان API (فقط موجود) کار می‌کند، نه با ۱۶ گزینهٔ صفحهٔ اول. رنگ و سایز دکمه‌ای است.
- پیامک تأیید مشتری سه بخش قابل‌ویرایش دارد: نام فروشگاه، جملهٔ کوتاه، کانال و شناسه. جملهٔ «تا تأیید نکنید…» و «پرداخت فقط به پوشاک ترنم» و خود لینک از سرور می‌آیند.
- ذخیرهٔ نام ترنم، لینک، شماره موبایل، شبا/کارت و کانال ناشناس رد می‌شود. پروفایل خراب در ارسال نادیده گرفته می‌شود و نام حساب جایگزین می‌شود.

## آزمون

`sales-partner-sms-profile.spec.ts`، `sales-partner-catalog-policy.spec.ts`، `sales-partner-draft-policy.spec.ts`، `sales-partner-isolation.spec.ts`.

## مهاجرت

`20261018-002-sales-partner-sms-profile.ts` چهار ستون nullable روی `sales_partner_profiles`. برگشت: حذف همان ستون‌ها. متن پیامک‌های قبلی ذخیره نمی‌شود.

## سئو

مسیرهای `/sales-partners` خصوصی و noindex هستند. این تغییر صفحهٔ عمومی نساخت.
