# داشبورد همکار: جزئیات پیش‌نویس سفارش

تاریخ: 2026-10-07  
تسک: TASK-20261007-006

## مشکل

در `/admin/sales-partners` تب سفارش‌ها، پیش‌نویس (`DRAFT` / در حال آماده‌سازی) در لیست دیده می‌شد ولی راهی برای باز کردن جزئیات نبود. فقط سفارش تبدیل‌شده لینک «سفارش فروشگاه» داشت. صف داشبورد هم فقط فیلتر تب را عوض می‌کرد.

## تصمیم

- جزئیات **read-only** در کشوی RTL هم‌سبک درخواست‌ها.
- ادامه ویرایش/ارسال لینک در پنل همکار می‌ماند (قوانین کسب‌وکار عوض نشد).
- API ادمین: `GET /admin/sales-partners/orders/:id` با اقلام، مبالغ، هشدار تازگی، همکار، مشتری ماسک‌شده. بدون توکن تأیید.

## الگوهای مرجع

- کشوی جزئیات روی صف عملیات (لیست باقی می‌ماند).
- Shopify/Medusa: وضعیت پیش‌نویس را جدا از سفارش نهایی نشان بده؛ تبدیل را صریح نگه دار.
