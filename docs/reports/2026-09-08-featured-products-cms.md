# گزارش: بلوک محصولات برتر CMS

تاریخ: ۲۰۲۶-۰۹-۰۸  
کار: TASK-20260908-005

## مشکل

در `/admin/site-content` بلوک «محصولات برتر» فیلدهایی داشت که ویترین اجرا نمی‌کرد: شناسه با کاما، مرتب‌سازی، دکمه مشاهده همه. عمده `limit` را به ۸ می‌بُرید و `sort`/`productIds` را نادیده می‌گرفت. تکی فقط `sort` و `limit` را می‌خواند. اپراتور باید UUID می‌چسباند.

## معماری اجراشده

منبع حقیقت کاتالوگ همان `GET /v1/products` است. CMS فقط چینش و متن را نگه می‌دارد.

- `auto`: sort + دسته اختیاری + تعداد + فقط‌موجود
- `manual`: لیست مرتب UUID؛ شناسه‌های نامعتبر/غیرفعال/کانال دیگر حذف می‌شوند؛ بدون fetch دوم
- سقف هوم ۱۲ کارت
- `isFeatured` دیتابیس عمداً استفاده نشد (deprecated = تخفیف)
