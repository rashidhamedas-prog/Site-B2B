# گزارش: CMS قابل‌ویرایش تمام صفحات (عمده + تکی)

تاریخ: 2026-07-28

## هدف
تمام متن‌ها، لینک‌ها، تصاویر و شمارنده‌های صفحه اول عمده (از نوار بالا تا فوتر) و سایر صفحات عمده/تکی از پنل ادمین قابل ویرایش، حذف و افزودن باشند.

## پیاده‌سازی
- مسیر ادمین: `/admin/site-content` با عنوان «تنظیمات محتوای سایت»
- کلیدهای صفحه: `chrome` (هدر/فوتر/شناور)، `home`، `about`، `contact`، `shipping`، `returns`، `wholesale`، حقوقی، …
- انواع بلوک جدید در ویرایشگر + پیش‌فرض‌های منطبق با محتوای قبلی
- رندر استورفرانت: `CmsPage` → `SiteBlocksRenderer`
- کانال RETAIL هیرو/FAQ/محصولات اختصاصی خودش را دارد

## نحوه استفاده مالک
1. ادمین → تنظیمات محتوای سایت (یا لینک داخل تنظیمات سیستم)
2. کانال عمده یا تکی را انتخاب کنید
3. تب صفحه را باز کنید (مثلاً صفحه اصلی یا هدر/فوتر)
4. بلوک‌ها را ویرایش / جابه‌جا / حذف کنید یا «پیش‌فرض این صفحه» را بزنید
5. ذخیره — پس از حدود یک دقیقه (revalidate) روی سایت دیده می‌شود
6. برای پر کردن اولیه همه صفحات: «ذخیره پیش‌فرض همه صفحات»
