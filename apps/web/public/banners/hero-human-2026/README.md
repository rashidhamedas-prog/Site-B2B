# Human-centered Hero 2026

نسخه بازطراحی‌شده Hero با عکس‌های انسانی اصلی پروژه و متن/CTA واقعی HTML.

- Desktop: `1600×900` WebP، quality 84
- Mobile: `900×1200` WebP، quality 82
- Wholesale: `wholesale-01..03`
- Retail: `retail-01..03`
- همه فایل‌ها کمتر از ۸۰KB هستند.
- هیچ متن، لوگو یا CTA داخل bitmap حک نشده است.
- تصاویر در UI تزئینی‌اند (`alt=""`) چون H1/H2/body معادل در HTML وجود دارد.

## قواعد استفاده

این تصاویر فقط با `presentation: overlay` استفاده شوند. متن باید در CMS باقی بماند و برای ساخت artwork جدید روی تصویر نوشته نشود. اسلاید نخست هر کانال `priority` است؛ تصاویر دیگر lazy باقی بمانند.

## محدودیت محتوایی

تصاویر فعلی مدل‌محورند. برای ارتقای بیشتر B2B، یکی از اسلایدهای عمده در آینده با عکس واقعی انسانی از کارگاه، کنترل کیفیت، رگال سفارش یا تیم بسته‌بندی ترنم جایگزین شود. از تصویر استوک یا ادعای تصویری غیرواقعی استفاده نشود.
