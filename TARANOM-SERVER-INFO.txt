# Taranom — Server Info (PUBLIC STUB)

این فایل دیگر credential واقعی نگه نمی‌دارد.

عملیات production (SSH، DB، Redis، MinIO، Meilisearch، JWT، SMS، payment)
باید فقط در vault / password manager / runbook خصوصی خارج از Git نگهداری شود.

برای راه‌اندازی محلی:
  1. از `.env.example` فایل `.env` بسازید
  2. همه CHANGE_ME ها را با secretهای قوی جایگزین کنید
  3. admin اولیه را با `SEED_ADMIN_PHONE` و `SEED_ADMIN_PASSWORD` بسازید:
       cd apps/api && npm run seed

هرگز رمز، token یا کلید واقعی را در این repo، WORKLOG، PR یا chat commit نکنید.

اگر قبلاً credential در این فایل یا تاریخچه Git بوده، آن‌ها را rotate کنید
(دستورالعمل: docs/chatgpt-hardening-handoff.md — Task 1 ops).
