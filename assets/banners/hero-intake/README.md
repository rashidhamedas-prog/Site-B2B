**اختیاری ولی خیلی مفید (تا ۳ تای دیگر):**
- ۱–۲ نمونه بنر «این خوبه» در `refs-good-bad/`
- ۱ نمونه «این بده / این را نساز»
- لوگو SVG اگر دارید (جایگزین PNG)

## مشخصات فنی

- فرمت: JPG / PNG / WEBP / HEIC
- حداقل ضلع بلند: **2000px** (ترجیح 3000px+)
- لایف‌استایل: فضای خالی یک‌طرف برای متن RTL (ترجیحاً سمت راست تصویر خالی‌تر)
- نور طبیعی یا استودیو تمیز؛ بدون واترمارک اینستاگرام
- همان لباس واقعی ترنم (نه استوک نامرتبط)
